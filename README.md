# Dr. Kunwar Pal — Academic Portfolio

A responsive, static academic portfolio website built with HTML, CSS, and JavaScript. It is suitable for hosting on GitHub Pages.

## Files

- `index.html` — website content and sections
- `style.css` — responsive design and styling
- `script.js` — mobile navigation and current year
- `.nojekyll` — tells GitHub Pages not to run Jekyll processing

## Publish using GitHub Pages

1. Sign in to GitHub and create a new repository. For a personal site, you can name it `yourusername.github.io`. Alternatively, use any repository name, such as `kunwar-pal-portfolio`.
2. Upload **all files in this folder** to the root of the repository. Make sure `index.html` is at the repository root, not inside an extra nested folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then click **Save**.
6. Wait for the deployment to finish. GitHub will show the published website URL in Settings → Pages.

For a repository named `yourusername.github.io`, the URL is usually `https://yourusername.github.io/`. For another repository name, it is usually `https://yourusername.github.io/repository-name/`.
